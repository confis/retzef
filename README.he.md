# רצף – אפליקציית Windows

נגן מצגות שמחבר PowerPoint, PDF, וידאו, תמונות, אתרים, שקופיות טקסט וטיימר הפסקה לרשימת הצגה אחת.
בגרסת Windows, קובצי PowerPoint מוצגים **ב-PowerPoint המותקן במחשב**, כך שהאנימציות, המעברים, הווידאו המוטמע, הגופנים וה-SmartArt נראים בדיוק כמו בקובץ.

## דרישות
- Windows 10 או 11, ‏64 ביט
- Microsoft PowerPoint מותקן (Microsoft 365, 2021, 2019 או 2016). בלי PowerPoint האפליקציה עובדת, וקובצי PowerPoint מוצגים בתצוגה המובנית.

## הפעלה מהירה (בלי התקנה)
1. חלצו את `Retzef-1.1.0-win-x64.zip` לתיקייה.
2. הפעילו את `Retzef.exe`. בהפעלה הראשונה Windows SmartScreen עשוי להזהיר כי הקובץ לא חתום: "מידע נוסף" ← "הפעל בכל זאת".
3. בתחתית רשימת ההצגה צריך להופיע "PowerPoint ‏16 מחובר".

## איך זה עובד בהצגה
- **שני מסכים (מחשב + מקרן):** חלון הקהל נפתח אוטומטית על המסך השני. כשמגיעים לקובץ PowerPoint, המצגת נפתחת ב-PowerPoint במסך מלא על המקרן, ורצף נשאר על המחשב כמסך מציג: השקף הנוכחי, השקף הבא, הערות הדובר והשעון. השלט או המקלדת ממשיכים לעבוד מול רצף, ורצף מעביר כל לחיצה ל-PowerPoint.
- **מסך אחד:** PowerPoint נפתח מעל רצף ומקבל את המקשים ישירות.
- בסוף המצגת, רצף ממשיך אוטומטית לפריט הבא. "הקודם" בשקף הראשון חוזר לפריט הקודם.
- Esc בתוך PowerPoint סוגר את המצגת. "הבא" ממשיך לפריט הבא.
- בתחתית הרשימה אפשר לבחור "תצוגה מובנית" במקום PowerPoint.

## בניית מתקין (על מחשב Windows)
צריך Node.js 20 ומעלה.

```bat
npm install
npm run dist
```

הקבצים נוצרים בתיקייה `dist`: מתקין (`Retzef-Setup-1.1.0.exe`) וקובץ נייד (`Retzef-Portable-1.1.0.exe`).
להפעלה לפיתוח: `npm start`.

## מבנה
| קובץ | תפקיד |
|---|---|
| `src/retzef.html` | הנגן עצמו. אותו קובץ משמש גם כגרסת הדפדפן |
| `build/prepare.js` | בונה את `app/index.html`: מחליף טעינה מהרשת בעותקים מקומיים (pdf.js, pptx-preview, גופנים) |
| `main.js` | תהליך Electron: חלונות, מסך קהל, שליטה ב-PowerPoint |
| `ppt-host.ps1` | שליטה ב-PowerPoint דרך ממשק האוטומציה (COM) של Windows |
| `fake-ppt.js` | הדמיה של PowerPoint לפיתוח ובדיקות על מחשב בלי PowerPoint |

## מה כדאי לבדוק בפעם הראשונה
1. מצגת עם אנימציות: כל לחיצה מפעילה את השלב הבא, ובמסך המציג מופיע "שקף X/Y · אנימציה".
2. עם מקרן: המצגת נפתחת על המקרן, ולא על מסך המחשב.
3. בסוף המצגת: מעבר אוטומטי לפריט הבא.

אם המצגת נפתחת על המסך הלא נכון, בחרו ב-PowerPoint: הצגת שקופיות ← הגדרת הצגת שקופיות ← צג.

## הערות
- הקבצים לא יוצאים מהמחשב. עותק של כל מצגת נשמר בתיקיית הנתונים של האפליקציה (`%APPDATA%\Retzef\presentations`) ונמחק כשמסירים אותה מהרשימה.
- בזמן ההצגה רצף מעדכן זמנית את הגדרת "צג הצגת השקופיות" של PowerPoint, ומחזיר אותה לקדמותה בסיום.
- דפי אינטרנט מוצגים בתוך האפליקציה גם כשהאתר חוסם הטמעה בדפים אחרים.
